# Catalog

Plugins of the `marketplace-base` marketplace. Generated by `./mb gen` from each plugin's
`plugin.src.json`, `SKILL.md` files and `config.defaults.json`. Do not edit.

| Category | Productivity |

| Org policy | - |
| Install (Claude Code) | `claude plugin install code-review@marketplace-base` |
| Install (Codex) | `codex plugin add code-review@marketplace-base` |

### Skills

| Skill | Description |
|---|---|
| `code-review-checklist` | Review a code diff or pull request against a configurable checklist (correctness, tests, security, docs, performance) and report a short, severity-ranked list of findings with file and line. Read-only; it never edits code. Use when the user asks to review a diff, a patch, staged or uncommitted changes, a branch or a pull request, or asks whether a change is safe or ready to merge. |

### Default settings

```json
{
  "checks": {
    "docs": false,
    "performance": false,
    "security": true,
    "tests": true
  },
  "maxItems": 10,
  "severityLabels": [
    "blocker",
    "major",
    "minor"
  ]
}
```

### Skills
